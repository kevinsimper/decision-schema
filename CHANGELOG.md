# Revision history

## v0.1.0-draft — 2026-10-20

Initial public draft, created by Kevin Simper.

- Define five shared logical tables: events, event lines, observations, decisions, and tasks.
- Define stable scoped subjects, provenance, evidence links, and type-specific extensions.
- Define immutable decision chains, scheduled review, and event-triggered reevaluation.
- Separate task execution from judgment and infrastructure from domain concepts.
- Include fictional insurance, workshop, and equipment-transfer examples and implementation guidance.

This release is a specification proposal. It includes no executable implementation, SDK, or claim of production conformance.
